# Write a frozen generated routing benchmark

Write a frozen generated routing benchmark

## Usage

``` r
write_agentic_routing_benchmark(benchmark, path, overwrite = FALSE)
```

## Arguments

- benchmark:

  A generated `agentic_routing_benchmark`.

- path:

  Destination JSON file outside the target repository.

- overwrite:

  Replace an existing file.

## Value

The normalized path, invisibly.
