# Record human review of generated competency questions

Record human review of generated competency questions

## Usage

``` r
review_agentic_routing_benchmark(
  benchmark,
  approve = character(),
  reject = character()
)
```

## Arguments

- benchmark:

  A generated `agentic_routing_benchmark`.

- approve:

  Question identifiers to approve.

- reject:

  Question identifiers to reject.

## Value

The updated benchmark.
