# Summarize an agentic-routing evaluation

Summarize an agentic-routing evaluation

## Usage

``` r
summarize_agentic_routing(evaluation)
```

## Arguments

- evaluation:

  Result from
  [`run_agentic_routing_evaluation()`](https://mvr-gis.github.io/reproducibleai/reference/run_agentic_routing_evaluation.md).

## Value

An object of class `agentic_routing_health`.
