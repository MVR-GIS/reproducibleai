# Read a frozen generated routing benchmark

Read a frozen generated routing benchmark

## Usage

``` r
read_agentic_routing_benchmark(path)
```

## Arguments

- path:

  Benchmark JSON written by
  [`write_agentic_routing_benchmark()`](https://mvr-gis.github.io/reproducibleai/reference/write_agentic_routing_benchmark.md).

## Value

An object of class `agentic_routing_benchmark`.
