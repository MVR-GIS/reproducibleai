# Install the parameterized-help instruction module

Installs the canonical `parameterized-help` instruction text and
scaffolds a starter help-data framework for package-based Shiny apps.

## Usage

``` r
module_parameterized_help(path = ".", overwrite = FALSE, ...)
```

## Arguments

- path:

  Character scalar path to the target repository root.

- overwrite:

  Logical scalar; whether handler-owned files may be overwritten.

- ...:

  Reserved for future extensibility.

## Value

A standard module result object.
