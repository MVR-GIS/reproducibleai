# Read agentic-routing competency questions

Read agentic-routing competency questions

## Usage

``` r
read_agentic_routing_questions(path)
```

## Arguments

- path:

  Versioned JSON fixture written by
  [`write_agentic_routing_questions()`](https://mvr-gis.github.io/reproducibleai/reference/write_agentic_routing_questions.md).

## Value

A list of `agentic_routing_question` objects.
